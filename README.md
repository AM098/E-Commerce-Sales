# E-Commerce-Sales
E-Commerce Sales Analysis
Sales and profit analysis using Python (Pandas, Plotly) to explore sales trends over time and performance by category, sub-category, and customer segment.

##  Project Overview
This project analyzes a retail sales dataset using Python to find out what drives sales and profit.

What the analysis covers:
     - Data cleaning and date conversion (order month, year, and day of the week)
     - Monthly sales and profit trends
     - Sales and profit by category and sub-category
     - Sales and profit by customer segment
     - Sales-to-profit ratio analysis

Tools used: Python, Pandas, NumPy, Plotly
Suggested topics/tags: python pandas, plotly, data-analysis, eda, sales-analysis, profit-analysis And data-visualization
